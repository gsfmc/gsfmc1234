# 광산 생활배출 길잡이

광산구 시민이 휴대폰에서 생활폐기물 배출 방법을 빠르게 확인하는 앱형 웹사이트입니다.

## 주요 기능

- 촬영·업로드한 사진을 Gemini 비전 모델이 직접 분석
- 예상 품목, 배출 구분, 분리할 부분, 배출 전 처리방법, 주의사항을 단계별 안내
- 불확실한 사진은 단정하지 않고 가능한 품목과 추가 확인 질문 제시
- 공공데이터포털의 전국종량제봉투판매소표준데이터에서 광산구 영업 중 판매소를 추출해 제공
- 현재 위치 또는 입력 주소 기준 가까운 순 정렬, 지도와 길찾기
- 동별 수거 일정은 공단 자료 수령 후 연결 예정

## 운영 환경값

- `GEMINI_API_KEY`: Google AI Studio에서 발급한 Gemini API 키. 반드시 Sites 비밀 환경값으로 저장합니다.
- `GEMINI_MODEL`: 선택 사항. 기본값은 `gemini-3.8-flash`입니다.

API 키는 브라우저와 GitHub 소스에 포함하지 않습니다. 사진은 서버가 Gemini API에 전달하며 앱이 별도로 저장하지 않습니다.

## 데이터 출처

종량제봉투 판매소는 [공공데이터포털 전국종량제봉투판매소표준데이터](https://www.data.go.kr/data/15114144/standard.do)를 사용합니다. 표준데이터에 없는 봉투 종류는 표시하지 않으며, 제공되는 대형폐기물스티커 판매 여부를 함께 보여줍니다.

## 빌드

`npm run build`를 실행하면 화면 자산을 포함한 `dist/server/index.js`가 생성됩니다.
