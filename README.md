# 광산 버릴지도

광산구 시민이 휴대폰에서 생활폐기물 배출 방법을 빠르게 확인하는 앱형 웹사이트입니다.

## 주요 기능

- 촬영·업로드한 사진을 Gemini 비전 모델이 직접 분석
- 예상 품목, 배출 구분, 분리할 부분, 배출 전 처리방법, 주의사항을 단계별 안내
- 불확실한 사진은 단정하지 않고 가능한 품목과 추가 확인 질문 제시
- 분석 결과마다 추천 질문 3개와 직접 추가 질문. 같은 사진·설명·분석 결과 및 최근 대화를 Gemini에 함께 전달해 답변
- 추가 대화는 현재 화면 메모리에서만 유지하고, 사진 교체·삭제·재분석 시 초기화
- 공공데이터포털의 전국종량제봉투판매소표준데이터에서 광산구 영업 중 판매소를 추출해 제공
- 현재 위치·동·도로명·판매소명 검색, 지도 범위별 목록과 숫자로 묶은 판매소, 카카오맵 도보 길찾기
- 공단 정기 수거 안내와 현재 위치에 따른 우리동네 수거일
- 사진 분석 → 해당 배출 구분의 수거일 → 봉투 판매소 연결. 분석 결과로 돌아와도 사진과 추가 대화를 유지
- 선택한 동네를 판매소 검색에 전달하고, 최근 5분 이내 확인한 GPS 위치를 재사용. 선택 지역·좌표·분석 맥락은 현재 페이지 메모리에서만 유지
- 판매소 화면에서도 선택한 판매소의 행정동 또는 조회 중인 동네의 수거일로 이동. 사진 분석 없이 수거일과 판매소를 양방향으로 연결
- 첫 화면과 상단에서 한국어·베트남어·중국어 간체·러시아어·영어·크메르어 선택. 언어 설정만 기기에 저장하며 새 AI 분석·추가 답변에도 전달
- 고정 UI 번역을 앱에 포함해 번역 API 없이 전환. 공식 상호·주소는 한글을 유지하고 동 선택에는 영문 표기를 병기
- 복합·별도·불확실한 배출은 일반 수거 일정으로 단정하지 않고 해당 안내를 먼저 표시

## 운영 환경값

- `GEMINI_API_KEY`: Google AI Studio에서 발급한 Gemini API 키. 반드시 Sites 비밀 환경값으로 저장합니다.
- `GEMINI_MODEL`: 선택 사항. 기본값은 `gemini-3.5-flash`입니다.

API 키는 브라우저와 GitHub 소스에 포함하지 않습니다. 사진은 서버가 Gemini API에 전달하며 앱이 별도로 저장하지 않습니다.

## 데이터 출처

종량제봉투 판매소는 [공공데이터포털 전국종량제봉투판매소표준데이터](https://www.data.go.kr/data/15114144/standard.do)를 사용합니다. 표준데이터에 없는 봉투 종류는 표시하지 않으며, 제공되는 대형폐기물스티커 판매 여부를 함께 보여줍니다.

## 빌드

`npm run build`를 실행하면 화면 자산을 포함한 `dist/server/index.js`가 생성됩니다.

## 판매소 자료 갱신

2026-11-03 공공데이터포털에서 확인한 광산구 자료는 2026-10-21 기준이며, 제공기관 수정일은 2026-10-22입니다. 제공기관 전체 760행에서 광산구 소재·영업 중 736행을 사용합니다. 다른 지역 소재 24행은 제외하며 주소가 비어 있으면 지번주소를 사용합니다. 원문 좌표와 판매소 이름을 유지합니다.

수동 갱신은 npm run update:stores로 실행합니다. 공식 포털 다운로드를 검증한 뒤 기준일·확인일을 기록하고 브라우저 캐시 버전도 갱신합니다. 실행 후 npm run build로 반영합니다.
