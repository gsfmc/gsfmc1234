# Administrative-dong boundary attribution

`public/gwangsan-dongs.geojson` contains only the 21 Gwangsan-gu features extracted
from `HangJeongDong_ver20260701.geojson` (2026-07-01), with the geometry unchanged.

Source: https://github.com/vuski/admdongkor/tree/master/ver20260701
License: https://github.com/vuski/admdongkor/blob/master/LICENSE-DATA

This data is derived from administrative-dong boundaries released by Statistics
Korea SGIS (https://sgis.kostat.go.kr) under KOGL Type 1, modified by
vuski/admdongkor (https://github.com/vuski/admdongkor), distributed under CC BY 4.0.

The source dataset does not guarantee boundary accuracy. Location estimates must
be confirmed near administrative boundaries. Industrial-complex collection
regions are selected separately and are not inferred from administrative-dong data.

Collection weekdays and times are separately sourced from GSFMC's guide:
https://www.gsfmc.or.kr/html/03030100 (checked 2026-11-03).
